# Cats API

Учебный проект по работе с API.

Программа получает изображение кота с заданным текстом через [CATAAS](https://cataas.com/) и загружает его на Яндекс.Диск. Информация о загруженных файлах сохраняется в JSON.

## Установка

*Установить зависимости:*

`pip install -r requirements.txt`


## Запуск

*Запустить main.py и ввести:*

1. Текст для изображения.

2. Токен Яндекс.Диска.
